## How It Works (Engine Architecture)
1. **Input Ingestion & Token Normalization:** Scheduled triggers launch decoupled execution workers alongside heartbeat sentinels that ingest runtime metrics, exit codes, process states, and standard error streams in real time.
2. **Cognitive Processing Layer:** Upon detecting a task timeout or non-zero status code, orchestrator nodes isolate the fault, evaluate stack traces, execute containerized restart/fallback subroutines, and auto-correct corrupt states.
3. **Deterministic Output & Synthesis:** The system synthesizes immutable audit logs, updates global operational state, and formats high-priority diagnostic alerts dispatched instantaneously via encrypted Telegram Bot API webhooks.
