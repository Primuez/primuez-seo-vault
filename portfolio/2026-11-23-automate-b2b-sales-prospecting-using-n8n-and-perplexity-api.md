## How It Works (Engine Architecture)
1. **Input Ingestion & Token Normalization:** Target company domains or ICP trigger signals are captured via webhooks, Google Sheets, or webhook endpoints, and normalized into uniform JSON payloads within n8n.
2. **Cognitive Processing Layer:** n8n dispatches asynchronous requests to the Perplexity API using live search parameters to extract current financial events, tech stack changes, hiring patterns, and decision-maker profiles.
3. **Deterministic Output & Synthesis:** Responses pass through validation nodes enforcing strict Pydantic-style JSON schemas, dynamic icebreaker generation, deduplication against CRM records, and automated dispatch to HubSpot, Salesforce, or automated cold outreach engines.
